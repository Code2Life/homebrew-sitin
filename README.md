# Homebrew tap for Antroom

[Antroom](https://antroom.tos.run/): meetings, issues and AI agents for small teams.

```sh
brew install --cask code2life/antroom/antroom
```

The desktop app for macOS (Apple silicon and Intel, macOS 13 or later). It is a development build,
ad-hoc signed and not notarized; the cask removes the quarantine attribute so it opens without a
Gatekeeper prompt. The app updates itself.

The command line `ant` (macOS and Linux): `curl -fsSL https://antroom.tos.run/install.sh | sh`.

This repository is generated by the Antroom release pipeline on every stable release.
